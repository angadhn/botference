Botference Discuss

What the bots bill to, and — only if you need it — where the companion lives.

API keys

Optional. Discuss runs on whatever the claude and codex CLIs are logged into; a key here makes that agent bill the key instead. This page is the only place a key is ever typed — the drawer sits inside the pages you read, so nothing secret goes in it.

Used as ANTHROPIC_API_KEY when the bots run. Claude Code prefers a key over your subscription whenever one is set.

Used as OPENAI_API_KEY when the bots run — but note that Codex only falls back to a key when it is not logged in with ChatGPT. If you are logged in, the login wins; run codex login --with-api-key to change that.

Keys are kept on the companion's machine in a 0600 file and are never sent back to this page — it only ever learns “set” or “unset”. They can only be set from the machine the companion runs on, never over a tunnel. Each agent's billing switch lives in the drawer's ⚙ menu; with a key saved it starts on API key, and without one it cannot leave subscription.

Remote companion — optional

Only if this browser talks to a companion on another machine. Most people never touch any of this: leave it empty and the extension uses the companion running on this Mac (http://127.0.0.1:4189, started with botference discuss).

Empty means the local companion at http://127.0.0.1:4189. A hosted one is its https address.

Leave empty for your own machine. A hosted companion's password is sent as a bearer token on every request — never as a cookie.

Signs every comment you post and picks your colour in the drawer. Only used when a password is set.

Settings apply immediately — the extension reconnects on save. No page reload needed.
