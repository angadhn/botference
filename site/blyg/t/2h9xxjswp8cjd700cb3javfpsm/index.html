the botference blyg

botference is five tools

Botference runs Claude Code and Codex side by side. It uses the command-line tools that you already have, on your own computer. It started as a planning council. It now holds five tools, and you can use each one alone.

  • Council. You, Claude and Codex plan in one chat, in your terminal. A bot can hand the floor to the other bot, so the two argue a point before they come back to you. Planning is the most mature part of botference.
  • Discuss. A browser extension and a small local server, the companion. Highlight a passage on any web page, write a comment, and mention @claude, @codex or @all. The bots answer in the same thread, at the side of the page.
  • Document review. Margin comments on a LaTeX or Markdown source, rendered as a web page. Tag a bot in a comment, and it answers or suggests a change.
  • Blygger publishing. Publish a Discuss thread to your own site as a blyg post. This part is experimental.
  • Agent tools. botference see takes a phone and a desktop screenshot of a page for a coding agent. botference service keeps a server running after the agent's shell ends.

One person builds botference for their own work, so some parts assume that person's set-up. The home page says who each tool is for and how ready it is. The source is on GitHub, under the MIT license.

This blyg holds release notes and short posts about botference. It is itself made by a small script in the repository, from Markdown files.
